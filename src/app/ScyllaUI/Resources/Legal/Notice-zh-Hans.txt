3. 第三方 CLI 与 AI 服务

ScyllaUI 是一个终端和状态面板，本身不提供 AI 服务。您在它的终端里运行的 AI 编程工具（例如 Claude Code、Codex、Kimi Code、Grok Build、OpenCode、GitHub Copilot CLI、Antigravity CLI，以下称「第三方 CLI」）及其连接的 AI 服务都由各自的提供方提供，适用它们自己的条款；账号、费用与额度由您与相应提供方之间处理。

ScyllaUI 不属于任何第三方 CLI，与它们的开发者没有关联，也未获其认可。软件中出现的第三方名称和标志只用来标识对应的工具，相关商标归各自所有者。


4. Agent 的行为由您决定

- 第三方 CLI 里的 AI（以下称「Agent」）在终端里执行的命令、对文件的修改和删除、发出的网络请求及由此产生的费用，由您和相应第三方 CLI 决定和负责。
- ScyllaUI 显示的状态、通知、额度、提示词与回复摘要，都来自第三方 CLI 提供的信息，可能延迟、不完整或不准确，只供参考，不应作为判断 Agent 是否安全的唯一依据。
- 操作审批由第三方 CLI 发出、由您本人决定，ScyllaUI 不替您批准任何操作。
- 建议您对重要的代码和数据使用版本控制并定期备份。


5. 对您系统的修改

为同步 Agent 状态、显示用量，ScyllaUI 会在第三方 CLI 的配置文件里写入它自己的条目：状态同步（Hook）在 App 里先列出改动，经您确认后才写入；Claude Code 的 statusline 桥只在您自己运行安装命令时写入（可以先运行查看改动的命令）。写入前都会备份原文件，您可以随时撤销。除此之外，ScyllaUI 不修改第三方 CLI 的配置。


6. 隐私

ScyllaUI 如何处理数据，见《ScyllaUI 隐私与数据说明》（「设置 › 关于 › 隐私说明…」）。ScyllaUI 不收集、不上传您的使用数据。
