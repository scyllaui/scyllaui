5. Changes to your system

To sync Agent status and show usage, ScyllaUI writes its own entries into the configuration files of Third-Party CLIs: status sync (hooks) lists the changes in the app and is written only after you confirm; the Claude Code statusline bridge (used to show Claude's quota) is checked by default when you install status sync, you can uncheck it, and it too is written only after you confirm. The original files are always backed up before writing, and you can undo the changes at any time. Apart from this, ScyllaUI does not modify the configuration of Third-Party CLIs.
