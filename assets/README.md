## App 图标维护

- 唯一当前母版为 `scylla-app-icon.png`，不是六头开屏母版。修改后同步 `.icon` 内的同名副本，核对 SHA-256 一致。本次定稿 SHA-256：`7cc092c2a3b4e21a50c1b87e3fd00a84f6daddcbeb23fe5540e771e02536abb7`。
- 定稿来源：`output/icon-redesign-20261115/r14-parallelogram/scylla-parallelogram.png`，该目录的 `prompt.json` 与 `generated-original.png` 保留内置 image_gen 的局部编辑指令和原始输出。预览沿用既有 `export-master.swift`：1254 px 图源等比映射至 824 px 圆角区域，放入 1024 px 画布；裁掉边界外杂点，图内透明像素合成到黑底，RGB 各通道不大于 2 的近黑噪声统一为 0。正式母版直接复制已验收的规范预览，不再次生成或调色；保留 sRGB 与图外透明。采用与资源校验记录在 `output/icon-adoption-20261115-redline/`。`output/` 不入库；仓库中的 PNG 与本文件记录的 SHA-256 是正式母版依据。
- 母版透明范围内的可见圆角区域为 `100 ≤ x,y < 924`，宽高 824 px；图层设 `position.scale = 1024 / 824 = 1.2427184466019416`、`translation-in-points = [0,0]`。这个比例抵消系统图标布局再次添加的外边距，不拉伸龙头，避免双重留白。图标背景填充与图内底色均为 `#000000`。
- 不要把 App 图标母版覆盖到 `scylla-pseudo-pixel.png`（那是开屏母版），也不要为了换 App 图标重跑开屏生成脚本。
- 工程配置仍为 `ASSETCATALOG_COMPILER_APPICON_NAME = Scylla`，Release / Debug 共用同一资源；替换仓库资源不等于更新已安装的正式版。资源校验记录见 `output/icon-adoption-20261115-redline/`；独立原生预览与 64 / 32 / 16 pt 检查记录在 `output/icon-redesign-20261115/r14-parallelogram/dock-preview-check.json`。预览窗口已核对，Dock 画面因工具读取超时未由助手目视验证；用户随后确认定稿。

## 六头开屏维护

- 2026-11-06 用户确认新版连续色块与像素纹理，色调回到原母版的冰蓝、浅青和钴蓝。保留六首共身、交织长颈和底部 `>_`。11-07 增加内侧颈部自然弯曲，最终恢复粗壮版本；用户查看 Beta 深浅开屏后确认验收。
- 当前深浅原图为用户要求恢复的粗壮版本：浅色 `exec-e77f7259-2083-44c9-9ca1-540a265f6513.png`，深色 `exec-2fa50e3d-bba6-4382-a339-bcdca2a84e62.png`。由内置 imagegen 局部编辑生成；项目文件与对应输出逐字节一致，不从对比图裁切重建。编辑方向为「保留轻微 S 形生理弯曲，加宽凹陷颈段，使钴蓝核心与浅青高光连续；六头、交织关系和底部符号不变」。
- 对比图仅用于整体视觉比较；精确颜色与形状以独立母版为准。浅色轮廓不超过 1pt、内部对比度提高约 20% 是设计目标，生成式栅格图尚未数值校准。
- `generate-splash-art.swift` 读取六头深色母版，输出一个身体、六个头与六张沿颈部距离图。六头顺序为左上、右上、左中、右中、左下、右下；种子、切口、支点及包围盒记录在 `splash-art.json`。非切口边必须走背景，脚本发现穿过前景即失败；切口两侧有 18 px 静止重叠带，轮廓也延伸到重叠带。原有 5 秒时间线和摆角保持不变。开屏深浅主题共用这套几何，浅色把轮廓减至 3 个源像素（340 pt 标准显示尺寸下约 0.94 pt），不直接裁切独立浅色母版。
